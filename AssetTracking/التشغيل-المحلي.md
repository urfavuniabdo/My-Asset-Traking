# تشغيل النظام محلياً — دليل مختصر

> **لا تحتاج SQL Server ولا IIS.** بيئة التطوير تستخدم SQLite، والقاعدة
> والبيانات التجريبية تُنشأ تلقائياً عند أول تشغيل.
> المطلوب الوحيد: **.NET 8 SDK** (مجاني).

---

## ⚠️ تنبيه: الريبو يحتوي نظامين مختلفين

| النظام | المكان | الثيم | كيف يُشغَّل |
|---|---|---|---|
| **.NET MVC** (هذا الدليل) | `AssetTracking/` | **أخضر** `#0f766e` | `run-local.ps1` |
| Hono + Cloudflare D1 | جذر الريبو (`src/`, `public/`) | أزرق `#3b82f6` | `npx wrangler pages dev` |

**سجل أعطال الماكينات وزمن التوقف المحسوب وشجرة التصنيفات** موجودة في
نظام **.NET الأخضر** فقط. لو شغّلت تطبيق Hono فسترى الواجهة الزرقاء
القديمة بلا هذه الميزات.

## التشغيل في خطوة واحدة

### Windows (PowerShell)
```powershell
cd AssetTracking
.\run-local.ps1
```

لو منعت سياسة PowerShell تشغيل السكربت:
```powershell
powershell -ExecutionPolicy Bypass -File .\run-local.ps1
```

### Linux / macOS
```bash
cd AssetTracking
./run-local.sh
```

السكربت يتولّى: التحقق من .NET 8 ← التحقق من إصدار الكود ← البناء ←
إنشاء القاعدة والبيانات ← التشغيل ← فتح المتصفح.

## الخيارات

| الخيار | الاستخدام |
|---|---|
| `-Fresh` / `--fresh` | يحذف القاعدة ويعيد توليد البيانات التجريبية |
| `-Clean` / `--clean` | **يحذف `bin/` و`obj/`** — استخدمه لو رأيت نسخة قديمة |
| `-Port 5050` / `--port=5050` | منفذ مختلف (الافتراضي 5000) |

### 🔑 «أرى نسخة قديمة» — الحل

`bin/` و`obj/` **مُستثناة في `.gitignore`** (وهذا صحيح)، فـ`git pull`
يحدّث الكود المصدري لكن **لا يلمس** مخرجات البناء القديمة عندك:

```powershell
git pull
.\run-local.ps1 -Clean -Fresh
```

ثم في المتصفح **`Ctrl + Shift + R`** — لأن `_Layout.cshtml` يستخدم
`asp-append-version` الذي يحسب بصمة CSS وقت البناء، فالمتصفح قد يخدم
نسخة مخزّنة.

## تجربة سجل أعطال الماكينات

ادخل بحساب `delta.manager@ats.eg` ← **تذاكر الصيانة**، وستجد التذاكر
`TKT-2026-00901` … `00905`:

| التذكرة | الماكينة | الخط | فئة العطل | زمن التوقف |
|---|---|---|---|---|
| 00901 | Station 04 (Press) | Line 1 | ميكانيكي | 45 دقيقة |
| 00902 | Optical Sensor 02 | Line 2 | حساسات | 25 دقيقة |
| 00903 | PLC Gateway Unit | Line 1 | برمجيات / MES | 30 دقيقة |
| 00904 | Pneumatic Loader | Line 3 | هوائي | 20 دقيقة |
| 00905 | Conveyor Motor 01 | Line 2 | كهربائي | 35 دقيقة |

### أثبت أن زمن التوقف محسوب تلقائياً
1. **تذكرة جديدة** ← اختر `Station 04 (Press)` (خط الإنتاج يُملأ وحده)
2. **وقت توقف الماكينة** = `10:00` ← احفظ
3. التذكرة تظهر **«متوقفة الآن»** والزمن يزيد لحظياً
4. **تم الحل** ← غيّر **وقت استئناف التشغيل** إلى `11:17`
5. 👀 سطر «زمن التوقف المحسوب» يتغيّر فوراً إلى **«1 ساعة و17 دقيقة»** قبل الحفظ
6. احفظ ← المخزَّن = **77 دقيقة**

لا يوجد مكان تكتب فيه رقم الدقائق — هذا هو الحساب التلقائي.

## النشر على الإنتاج (SQL Server + IIS)

بيئة الإنتاج تستخدم SQL Server. الخطوات في `README.md` قسم
«التشغيل في بيئة الشركة»، وملخّصها:

```powershell
# 1) appsettings.Production.json
#    "DatabaseProvider": "SqlServer"
#    "ConnectionStrings:DefaultConnection": "Server=...;Database=AssetTracking;..."

# 2) تطبيق الترحيلات
dotnet ef database update --project src\AssetTracking.Infrastructure `
                          --startup-project src\AssetTracking.Web

# 3) النشر
dotnet publish src\AssetTracking.Web -c Release -o C:\inetpub\AssetTracking
```

> ⚠️ الترحيل `AddFactoryMaintenanceFields` (أعمدة سجل الأعطال) مكتوب
> بأنواع محايدة تعمل على SQLite وSQL Server، لكن **جرّبه على نسخة
> اختبارية قبل قاعدة الإنتاج**.
